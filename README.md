# Guess The Number

An interactive number guessing game developed using HTML, CSS, and JavaScript.

## Live Demo

[Play the Game](https://meno-cv.github.io/Guess-The-Number/)

## About

Guess The Number is a simple interactive web game where the player tries to guess a randomly generated number within a given range.

The project was created to practice JavaScript fundamentals and improve my understanding of interactive web development.

## Features

- Random number generation
- User input for guesses
- Feedback for each guess
- Tracks the number of attempts
- Interactive game interface
- Option to play again

## Technologies Used

- HTML5
- CSS3
- JavaScript
